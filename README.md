# ScanSnap SV600 for Astra Linux

Поддержка Fujitsu ScanSnap SV600 (`04c5:128e`, служебная камера
`04c5:13ba`) через стандартный интерфейс SANE без виртуальной машины Windows.

Проект дополняет штатный backend `fujitsu`: воспроизводит подготовку лампы и
ИК-подсветки, команды оригинального Windows-минидрайвера и специальный SV600
`SET WINDOW`, без которого команда `SCAN` зависает. Полученный от сканера RGB
проходит точную заводскую поканальную оптическую карту PFU из оригинального
`SV600u-x64.dll`, а не подобранную на глаз геометрическую коррекцию. Эта карта
одновременно устраняет перспективное искажение оптической развёртки и
хроматическое расхождение R/G/B. Также пакет устанавливает правила доступа к
обоим USB-интерфейсам. После установки сканер доступен в Simple Scan, XSane,
NAPS2 и других программах, работающих через SANE.

На реальном SV600 проверены фиксированные A3L, A4L и A5L, автоматическое
определение A4, а также Color, настоящее 8-битное Gray и упакованное 1-битное
Lineart. Прошивка принимает только аппаратный Color 300 dpi; Gray и Lineart
формируются после заводской RGB-коррекции и отдаются приложению в штатных
форматах SANE. При Lineart ширина может уменьшиться не более чем на семь
пикселей, потому что одна строка должна занимать целое число байтов.

Поведение размеров разделено так же, как в ScanSnap Home:

- A3, A4 или A5 в графической программе включают фиксированный заводской crop
  A3L/A4L/A5L. Он гарантирует точный физический прямоугольник и не меняет его
  по найденному содержимому. В A4/A5 тёмный стол до первой устойчивой полосы
  светлой бумаги закрашивается белым без обрезки и масштабирования; пометки
  внутри листа, включая самый ближний к сканеру угол, сохраняются.
- стандартная рамка Letter/значение по умолчанию включает `Automatic detection
  (A4/Letter landscape)`: backend ищет реальные четыре угла, исправляет наклон
  и перспективу, удаляет стол по краям и возвращает A4 нужной ориентации.

Фиксированный A3L при 300 dpi имеет 4961×3506 пикселей, A4L — 3508×2479,
A5L — 2481×1747; портретная ориентация получается перестановкой готовых
пикселей без дополнительной интерполяции. Фирменная постобработка книг
ScanSnap Home (индивидуальное исправление изгиба раскрытой книги, удаление
пальцев, разделение нескольких документов и автоматическое перелистывание) в
backend не реализована.

## Установка

Скачайте один `.deb` из последнего GitHub Release и установите его:

```sh
sudo apt install ./scansnap-sv600-sane_*_amd64.deb
```

После установки переподключите сканер и камеру. Для обычной работы используйте
графическую программу сканирования; отдельный консольный процесс для камеры не
нужен. При диагностике обнаружение можно проверить командой `scanimage -L`.

Штатная укладка производителя для A3/A4/A5 — только landscape: лицом вверх,
длинной стороной параллельно основанию сканера и по центру центральной метки.
Именно так дальний край остаётся в более качественной части оптики. В программе
при этом можно выбрать портретный A4/A5: backend всё равно снимает лист в
штатном поперечном положении и поворачивает готовый результат. Оригинальный
матовый Background Pad рекомендуется производителем; Auto может сработать и на
контрастном столе, но без Pad распознавание границы не гарантируется.

Пакет временно подменяет только backend `fujitsu` при помощи `dpkg-divert`.
Все остальные SANE-сканеры остаются без изменений; при удалении пакета
оригинальный backend автоматически восстанавливается.

## Локальная сборка

На Debian/Astra требуются Autotools, Git, Python 3, `dpkg-dev`, `pkg-config` и
заголовки libusb. Затем:

```sh
VERSION=0.1.0 ./packaging/build-deb.sh
```

Каждый push в `main` собирается в контейнере Debian 10 и публикуется отдельным
автоматическим GitHub Release.
