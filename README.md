# ScanSnap SV600 for Astra Linux

Поддержка Fujitsu ScanSnap SV600 (`04c5:128e`, служебная камера
`04c5:13ba`) через стандартный интерфейс SANE без виртуальной машины Windows.

Проект дополняет штатный backend `fujitsu`: воспроизводит подготовку лампы и
ИК-подсветки, загружает таблицу коррекции и формирует специальный SV600
`SET WINDOW`, без которого команда `SCAN` зависает. Также пакет устанавливает
правила доступа к обоим USB-интерфейсам. После установки сканер доступен в
Simple Scan, XSane и других программах, работающих через SANE.

На реальном SV600 проверены последовательные цветные сканы 100×100 мм, A4 и
полного поля A3 432×300 мм, включая работу без отдельно запущенного потока USB
Camera. Именно A3 используется как максимальная геометрия SANE: больший размер
из служебных данных устройства прошивка фактически отвергает. Прошивка устройства
принимает только аппаратный режим Color 300 dpi, поэтому backend дополнительно
предоставляет стандартный программный режим Gray: приложения получают настоящее
8-битное изображение в оттенках серого и позволяют выбрать его в интерфейсе.

Для плоских документов backend по умолчанию сам находит лист в полном поле,
обрезает фон, исправляет перспективу и калиброванное двумерное искажение
развёртки SV600, совмещает расходящиеся красный и синий каналы с зелёным, а
A4/A3 приводит к точному стандартному соотношению сторон. Поиск углов уточняется
на полном разрешении, поэтому прямые внутри листа не искривляются из-за грубой
рамки документа. Simple Scan и другие обычные SANE-программы получают уже
выровненное изображение без цветных контуров и ручных консольных фильтров.
После геометрической коррекции backend отдельно оценивает загрязнение каждой
стороны и минимально подрезает только попавшие в кадр стол или краевую тень,
сохраняя точный выходной размер A4/A3. Фиксированная белая рамка не добавляется.
Фирменная постобработка книг ScanSnap Home
(индивидуальное исправление изгиба раскрытой книги, удаление пальцев, разделение
нескольких документов и автоматическое перелистывание) в backend не реализована.

## Установка

Скачайте один `.deb` из последнего GitHub Release и установите его:

```sh
sudo apt install ./scansnap-sv600-sane_*_amd64.deb
```

После установки переподключите сканер и камеру. Для обычной работы используйте
графическую программу сканирования; отдельный консольный процесс для камеры не
нужен. При диагностике обнаружение можно проверить командой `scanimage -L`.

Лист A4 можно класть вдоль или поперёк стола. При включённых стандартных
параметрах обрезки и выравнивания backend внутри всегда захватывает полное поле
A3, поэтому портретная рамка A4 из графической программы не обрежет поперечно
лежащий лист. Ориентация содержимого сохраняется физической; повернуть готовую
страницу можно обычной кнопкой поворота в программе сканирования.

Пакет временно подменяет только backend `fujitsu` при помощи `dpkg-divert`.
Все остальные SANE-сканеры остаются без изменений; при удалении пакета
оригинальный backend автоматически восстанавливается.

## Локальная сборка

На Debian/Astra требуются Autotools, Git, Python 3, `dpkg-dev`, `pkg-config` и
заголовки libusb. Затем:

```sh
VERSION=0.1.0 ./packaging/build-deb.sh
```

Каждый push в `main` собирается в контейнере Debian 10 и публикуется отдельным
автоматическим GitHub Release.
