# ScanSnap SV600 для Astra Linux

Пакет добавляет Fujitsu ScanSnap SV600 (`04c5:128e`) в стандартный
интерфейс SANE. После установки сканером можно управлять из «Сканера
документов» (Simple Scan), XSane, NAPS2 и других графических программ,
поддерживающих SANE. Виртуальная машина и Windows для работы не нужны.

Это не приблизительный фильтр поверх снимка. Backend повторяет исследованную
цепочку ScanSnap Home 4.0.0:

- получает аппаратный RGB 300 dpi: 5572×4429 для A3/Auto и штатный сокращённый
  кадр 5572×2858 для A4/A5; затем точно повторяет расширение строки
  Windows-minidriver до логической ширины 5832;
- перед сканированием передаёт прошивке заводской `SET PRE READMODE` с точными
  размерами выбранного A3/A4/A5;
- применяет точную поканальную оптическую карту из `SV600u-x64.dll`, которая
  одновременно исправляет геометрию оптики и хроматическое расхождение;
- запускает через Wine оригинальные `P2IDIGCROP.dll` и `bookbound.dll` для
  штатных границ и геометрии A3L/A4L/A5L;
- применяет byte-exact gamma 1.0→1.8, затем для 150/200/600 dpi вызывает
  оригинальный `P2IATRES.DLL`;
- после resize повторяет 17³ sRGB LUT и USM выходной ветки ScanSnap Home;
- формирует Gray8 той же целочисленной операцией
  `(77R + 150G + 29B) >> 8`, что и `SsSvcConvRGBToGrayN`.

В пакет входят только зафиксированные по SHA-256 компоненты одной исследованной
версии ScanSnap Home. PE-код работает в отдельном процессе Wine и не
загружается в адресное пространство SANE-приложения.

## Поддерживаемые режимы

Форматы бумаги:

| Режим | 300 dpi | Назначение |
|---|---:|---|
| A3L | 4961×3506 | полный A3 или два A4 рядом |
| A4L | 3508×2479 | фиксированная центральная область A4 |
| A5L | 2481×1747 | фиксированная центральная область A5 |
| Auto | по найденному контуру | отдельный лист на контрастном фоне |

Доступны Color, 8-битный Gray и 1-битный Lineart, а также 150, 200, 300 и
600 dpi. Оптика физически снимает 300 dpi; 150/200/600 — штатное преобразование
ScanSnap Home, причём 600 dpi не добавляет новых оптических деталей.

A3 — именно полный фиксированный A3L. Один A4 при выбранном A3 остаётся внутри
кадра A3, а два A4 рядом не должны превращаться в узкий вертикальный файл.
A4/A5 используют фиксированные заводские области, а не найденный на глаз crop:
это также позволяет выбрать A4 и исключить большую часть соседней страницы
сшитого дела.

## Как укладывать лист

Штатная укладка A3/A4/A5 у производителя — landscape: лицом вверх, длинной
стороной параллельно основанию сканера, по центру центральной метки. A4 и A5
нельзя прижимать к левому или правому краю поля: соответствующая фиксированная
область находится по центру. В графической программе можно запросить портретный
результат — backend повернёт уже исправленную страницу без повторной
интерполяции.

Для Auto производитель рекомендует оригинальный матовый Background Pad. На
контрастном столе обнаружение обычно работает, но без Pad это не гарантируется.
Для фиксированных A3L/A4L/A5L Pad не определяет размер области.

USB Camera (`04c5:13ba`) нужна ScanSnap Home для page-turn и наблюдения за
движением. Для обычного ручного скана через SANE она не используется. Книжная
коррекция раскрытого тома, удаление пальцев и автоматическое перелистывание в
эту версию не входят.

## Установка

Скачайте единственный `.deb` из последнего GitHub Release:

```sh
sudo apt install ./scansnap-sv600-sane_*_amd64.deb
```

Переподключите основной USB-интерфейс сканера после установки. Диагностическая
проверка обнаружения:

```sh
scanimage -L
```

Пакет подменяет только backend `fujitsu` с помощью `dpkg-divert`. При
удалении пакета системный backend восстанавливается.

## Сборка

Локальной сборке дополнительно нужны MinGW i686 и пять hash-pinned vendor
файлов в `vendor/`. GitHub Actions получает их из закрытого служебного Release
`vendor-windows-4.0.0`, собирает Debian/Astra-совместимый пакет и публикует
один `.deb`:

```sh
VERSION=0.2.0 ./packaging/build-deb.sh
```

Подробные доказательства и контрольные размеры находятся в
[`docs/windows-driver-research.md`](docs/windows-driver-research.md).
